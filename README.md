Este repositório contém o website institucional e a **Landing Page Premium** da **Dra. Ingrid Medeiros** (Farmacêutica Clínica, Bioquímica e Especialista Esteta). O projeto foi desenhado sob os mais altos padrões de design moderno, proporcionando uma experiência digital sofisticada, intuitiva e focada na conversão de leads qualificados.

---

## 🌟 Diferenciais da Landing Page

O site foi estruturado para transmitir autoridade clínica, sofisticação e acolhimento:

1.  **Estética Visual Premium**: Cores quentes e elegantes baseadas em tons de marrom luxuoso, dourado sutil, areia e off-white, combinados com as fontes *Playfair Display* (para títulos clássicos) e *Plus Jakarta Sans* (legibilidade moderna).
2.  **Pré-Avaliação Digital Interativa (Quiz de 3 Passos)**: Um recurso de alta conversão (WOW Feature) que guia o paciente por uma simulação clínica virtual rápida, recomendando o protocolo estético ideal com base em suas queixas específicas e gerando um link direto para agendamento no WhatsApp com a indicação já preenchida.
3.  **Menu Dinâmico de Procedimentos**: Filtros interativos (Tabs) que dividem o menu de tratamentos de forma limpa e organizada (Estética Facial, Mesoterapia Capilar/Corporal e Procedimentos Complementares).
4.  **FAQ Interativo**: Seção com sanfonas (accordions) reativas para sanar as principais dúvidas das pacientes sobre aplicação de Botox, Harmonização Facial e PEIM de forma acolhedora.
5.  **Botão Flutuante WhatsApp Premium**: Atalho de agendamento com efeito hover de tooltip elegante.

## 💆‍♀️ Menu de Procedimentos Cadastrados

A Landing Page apresenta de forma refinada os tratamentos oferecidos pela Dra. Ingrid:

### ✨ Estética Facial
*   **Harmonização Facial**: Mapeamento e equilíbrio dos traços naturais.
*   **Ácido Hialurônico**: Preenchimento labial, olheiras e sulcos profundos.
*   **Aplicação de Botox (Toxina Botulínica)**: Prevenção e suavização de rugas dinâmicas.
*   **Bioestimuladores de Colágeno**: Tratamento de flacidez e sustentação de longo prazo.
*   **Rinopreenchimento & Estruturação de Contorno (Malar/Mento)**.
*   **Limpeza de Pele Profunda & Microagulhamento** com drug delivery.

### 💉 Mesoterapia (Intradermoterapia)
*   **Capilar**: Combate a falhas, queda capilar e fortalecimento de fios fracos.
*   **Corporal**: Redução de gordura localizada, combate a celulite e flacidez regional.

### 🔬 Complementares
*   **PEIM**: Procedimento Estético Injetável para Microvasos (secagem de vasinhos nas pernas).
*   **Remoção de Sinais** benignos de forma segura e rápida.

## 🛠️ Arquitetura e Tecnologias

O projeto foi construído utilizando tecnologias nativas para garantir carregamento instantâneo, excelente desempenho no Lighthouse e facilidade de manutenção:

*   **HTML5 Semântico**: Tags estruturadas de forma adequada para otimização extrema de **SEO** (Search Engine Optimization), títulos hierárquicos e metadados de compartilhamento (OpenGraph).
*   **CSS3 Moderno**: Utilização de variáveis CSS customizadas (`--color-primary`, `--font-serif`, etc.) para facilitar alterações de marca, design fluido com Flexbox/CSS Grid, transições de opacidade suaves e efeitos de vidro fosco (*glassmorphism*).
*   **JavaScript ES6+**: Manipulação limpa do DOM (Document Object Model) para controle de transição de passos do Quiz, renderização de resultados personalizados, alternância de abas de serviços e interatividade das perguntas frequentes (FAQ).

## 🚀 Como Executar Localmente

Como a Landing Page foi construída com tecnologias web puras, ela não necessita de etapas de compilação ou gerenciadores de pacotes para rodar:

1.  Clone este repositório em sua máquina:
    ```bash
    git clone https://github.com/idarlandias/site-ingrid-medeiros.git
    ```
2.  Navegue até a pasta do projeto:
    ```bash
    cd site-ingrid-medeiros
    ```
3.  Abra o arquivo `index.html` em qualquer navegador web (dando duplo clique no arquivo ou usando extensões como *Live Server* no VS Code).
